# Sablier Payroll PoD Port (`sablier-payroll-pod/`)

Phase 2 port of Sablier payroll user-story tests to PoD (simCOTI + Hardhat + pToken).

## Principles

- **`sablier-payroll/`** (sibling folder) — frozen Phase 1 native reference (`npm run test:sablier-payroll`)
- **Story files** under `test/stories/` are verbatim copies — do not edit assertion logic
- Evolve **contracts-src** + **`test/lib`** only
- Merkle leaf: `hash(index, recipient, hash(ct))` via `amountCommitment` (see `test/lib/merkle.ts`)

## Run

From `pod-dapp-ports`:

```bash
npm run test:sablier-payroll-pod
```

Or from this directory:

```bash
npm install
npm test
```

Requires sibling repos (`coti-pod-inbox-contracts`, `coti-contracts`, `pod-mpc-lib`, `sim-coti-node`, `pod-ecosystem-integration` for test harness), `COTI_BACKEND=sim`, and linked contracts (`npm run link:contracts` — run automatically by `npm test`).

## Layout

```
sablier-payroll-pod/
  contracts-src/    PayrollVault, PayrollCampaignFacade, PrivatePayrollCoti, mocks
  contracts/        Generated by link:contracts + sync (gitignored)
  test/stories/     S01–S31 (35 tests, copied from sablier-payroll)
  test/lib/         PoD scenario, merkle, facade, async mining
  docs/             Architecture, user-story evaluation, iteration gap reports
```

## Architecture (summary)

| Layer | Role |
|-------|------|
| **PayrollCampaignFacade** | Sablier-shaped API (`claim`, `claimTo`, `clawback`, `hasClaimed`, …) |
| **PayrollVault** | AVAX inbox client (async COTI verify + payout callback) |
| **PrivatePayrollCoti** | COTI verify, encrypted roster, `spent[runId][index]` |
| **test/lib** | Dual-chain deploy, merkle builder, `wrapCampaignFacade` async mining |

Story-by-story UI evaluation (native vs PoD): [USER_STORIES_EVALUATION.md](docs/USER_STORIES_EVALUATION.md).
